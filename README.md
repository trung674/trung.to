# trung.to

Personal site and blog of Trung Nguyen, built with [Astro](https://astro.build/) and [AstroPaper](https://github.com/satnaing/astro-paper) theme

## Commands

| Command           | Action                                   |
| :---------------- | :--------------------------------------- |
| `npm install`     | Install dependencies                     |
| `npm run dev`     | Start the local dev server               |
| `npm run build`   | Type-check and build the site to `dist/` |
| `npm run preview` | Preview the production build             |

Site settings live in `astro-paper.config.ts`; posts go in `src/content/posts/`.
